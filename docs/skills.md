# 技能（SKILL.md）导入说明

> 状态：**方案 A 已实现** —— 用户自行下载技能文件，App 只负责导入，并把正文作为
> 本地纯文本对话的系统提示。不执行脚本、不加载资源文件、不上传电脑。
>
> 适合 Agent Skills / SKILL.md 生态（skills.sh、SkillsMP 等目录）。

## 1. 技能是什么

技能是一个可移植的提示词包，通常是一个目录里的 `SKILL.md`：

```markdown
---
name: code-reviewer
description: 按团队规范逐条审阅代码
license: MIT
---

你是一名严格的代码审阅者。请按以下顺序检查……
```

- `name`、`description` 必填；`license`、`version` 可选；
- `---` 之间的 frontmatter 只解析一层 `key: value`；
- 后面的正文就是注入对话的提示词；
- 技能目录里可能还有 `scripts/`、`references/`、`assets/`，**手机端一律不读取**。

## 2. 导入方式

1. 在浏览器或电脑上下载技能文件：
   - 单个 `SKILL.md`（或任意 `.md`）；
   - 或包含 `SKILL.md` 的 `.zip`（取最浅的一层）。
2. App →「插件 → 技能 → 导入技能」，选择文件。
3. 确认弹窗会显示名称、描述、来源与正文字数；确认后写入本地。
4. 导入后默认启用，可在列表里随时开关或删除。

限制：

| 项目 | 限制 |
|---|---|
| 文件大小 | ≤ 8 MB（zip 同样） |
| 单个 `SKILL.md` | ≤ 512 KB，正文最多 30000 字 |
| 合并系统提示 | 最多 24000 字（多个技能 + 插件模板合计） |
| zip 内容 | 只读取 `SKILL.md`，其他文件忽略 |

## 3. 生效范围

- 只对**本地纯文本对话**生效：本机 API Key 直连、电脑 DeepSeek 账号模型两条通道都会带上。
- 电脑端「对话」「工作」不会注入手机技能；电脑端仍使用电脑上的插件与技能体系。
- 多个启用技能按导入时间倒序拼接；插件 `chatTemplate` 排在技能之后。
- 技能只作为 `system` 消息发送，不写入电脑端会话记录。

## 4. 数据与隐私

- 技能保存在 App 文档目录：`<App 数据目录>/skills/<id>/SKILL.md`；
- 同时写一份 `meta.json`（来源文件名、导入时间），便于展示；
- 开关状态存 SharedPreferences（`localSkill.<id>.enabled`）；
- 删除技能只删除手机副本，不影响电脑和原始文件；
- 技能正文会发送给你选择的模型供应商；**导入前请确认来源与内容可信**。

## 5. 安全边界

- 不执行技能里的脚本、命令、二进制；
- 不读取 zip 内的其他文件，不跟随符号链接（zip 解析只取 SKILL.md）；
- 不做网络请求；
- 技能是提示词，仍可能包含提示注入；App 只负责原样注入，不能保证内容安全。
  不建议导入来源不明的技能。

## 6. 自测清单

- [ ] 导入 `.md`：确认弹窗显示正确，导入后出现在列表且默认启用；
- [ ] 导入 `.zip`：能找到 `SKILL.md`，缺少时给出明确错误；
- [ ] 停用后本地对话不再带该技能（对比输入 token 数或模型回答风格）；
- [ ] 重启 App 后技能与开关状态保持；
- [ ] 删除后列表消失，再次导入可重新出现；
- [ ] 导入 8MB 以上文件、空文件、损坏 zip 时有可读错误，不崩溃。
